LiteStream Studio – Installer exit codes

The LiteStream Studio installer is built with NSIS and installs silently with /S (per-user, no administrator rights needed). Uninstall with /S from the uninstaller in the install folder.

Exit codeMeaning
0Installation completed successfully.
1Installation cancelled by the user.
2Installation aborted by the installer (for example, a required condition was not met).
Any other non-zero valueInstallation failed with an unexpected error.

The installer does not return dedicated codes for "already installed", "installation already in progress", "disk full" or "reboot required"; those situations are handled by the installer itself (it upgrades in place) or reported as a generic failure.
